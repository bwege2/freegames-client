# HyperRogue port: module map (stage 1)

Generated by `re/hyperrogue/tools/gen-api.py modules` from autohdr.h (the declarations `makeh` collects
from the `EX` annotations). One TypeScript module per C++ file: `X.cpp` -> `src/X.ts`. A function `f` in
namespace `ns` is exported as `ns_f`; variables are fields of `G` (src/globals.ts) under the same name.
Overloaded C++ functions: see PORTING.md ("Overloads").
