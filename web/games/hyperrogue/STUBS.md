autohdr.h and the stage-1 sources: it over-reports member functions with common names such as `adj`, and misses
unqualified uses inside a namespace; treat it as a checklist). For each later-stage C++ file: the names the
stage-1 files reference, and from where. Each such file gets a stub module `src/<file>.ts`, every stubbed
function marked `// STAGE1-STUB`, owned by the package PORTING.md ("Stubs") names.
