# Typing Warriors: license and credits

**Typing Warriors is made by an AI** (Claude, an AI by Anthropic, working for the freegames project): its rules,
its code, its word lists and its texts. It is a game of this website's own, not a port: there is no original
elsewhere. It has no pictures, fonts or sound files: the screens are HTML and CSS in the system's fonts, the
sounds are made in the browser while you play (`src/ui.ts`, oscillators).

## The keyboard layouts

`src/layouts.data.ts` says which character each key types on each level of a layout. Nothing of the source files
is copied but these facts: the generator compiles each layout with `xkbcomp` and writes the resulting table.

* **xkeyboard-config** (<https://www.freedesktop.org/wiki/Software/XKeyboardConfig/>): the X Keyboard Configuration
  Database, under MIT/X11-style licenses (its `COPYING` lists the copyright holders, among them the X Consortium,
  Sun Microsystems, Silicon Graphics, Digital Equipment Corporation and the layouts' contributors). The layouts
  taken from it: German and Swiss QWERTZ, US and UK QWERTY, French AZERTY, Dvorak, Colemak, Colemak-DH (ANSI and
  ISO), Workman, Norman, Bépo, Neo 2, NeoQwertz, NeoQwerty, Bone, Noted, AdNW, KOY, 3l.
* **The Neo layouts** are the work of the Neo project and its contributors (<https://www.neo-layout.org/>; in
  xkeyboard-config: Bernd Steinhauser, Erik Streb, and many other contributors). Bone, Mine, Noted, AdNW and KOY
  are their authors' layouts as that project documents them. **Mine** is not in xkeyboard-config; its table comes
  from the Neo project's own xkb file (`dl.neo-layout.org/mine_2.39`), which builds on xkeyboard-config's
  `de(neo_base)`. The download page states no license of its own for that file.
* Dvorak: August Dvorak. Colemak: Shai Coleman. Colemak-DH: the Colemak Mods project. Workman: OJ Bucao. Norman:
  David Norman. Bépo: the Bépo project. 3l: Jack Rosenthal. The names are used to say which layout is meant.
